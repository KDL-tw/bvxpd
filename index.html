New Data, No Problem

1. Get the file

Open Colorado SOS results & data ↗ or the historical election database ↗. Pick one election and one reporting moment.

2. One row, one candidate

CSV, TSV, or flat JSON. One row per race, candidate, and county, or a statewide total. Pull out grand totals, precincts, and voting-method splits.

3. Check it

Map the columns and compare totals to the source. Search summaries, ballot-return files, PDFs, and spreadsheets have to become candidate rows first.

Past Data

Bundled history comes with the app. Files you import stay in this browser, on this device. Clear the browser data and those imports are gone, so download a JSON backup first. A backup is the rows plus the notes, not the original file.
